# Gemeenten 2025 with name errors

The `package` layer with six gemeente names edited, in OGC:CRS84. Each edit is one kind of name-detect finding: an encoding artifact, decomposed accents, a double space, non-breaking spaces, a name in capitals and a case-variant duplicate. Running name-detect reports all six. Running name-clean fixes the first four and leaves the other two for review. See [AGENTS.md](AGENTS.md).
