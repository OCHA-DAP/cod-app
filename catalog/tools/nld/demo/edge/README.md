# Gemeenten and provincies 2025 for edge-match

An input and an overlay layer for edge-match, in OGC:CRS84, simplified to 100 m. `nld_admin2.parquet` has the 342 land gemeenten from the CBS Wijk- en Buurtkaart 2025, with `adm2_code` and `adm2_name`. `nld_admin1.parquet` has the 12 provincies from Kadaster Bestuurlijke Gebieden, which include water, with `adm1_code` and `adm1_name`. Running edge-match with per-feature fitting extends the gemeenten over the water until they fill their provincies. See [AGENTS.md](AGENTS.md).
