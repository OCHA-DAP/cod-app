# Gemeenten 2025

The 342 land gemeenten from the CBS Wijk- en Buurtkaart 2025, in OGC:CRS84 with the CBS column names. Boundaries are simplified to 100 m, with neighbouring gemeenten still sharing their edges. The provincie code and name come from CBS StatLine table 86059NED (Gebieden in Nederland 2025). Running schema-map on it maps the gemeente columns to adm2 and the provincie columns to adm1. It drops `landcode`, `landnaam`, `water` and `jaar` because each holds a single value. See [AGENTS.md](AGENTS.md).

## Schema

| Column | Type | Description |
|--------|------|-------------|
| geometry | binary | Polygon or MultiPolygon in OGC:CRS84, simplified to 100 m in OGC:CRS84 (RD New) with `ST_CoverageSimplify` so neighbouring gemeenten keep shared edges. |
| gemeentecode | string | Gemeente (municipality) code: `GM` plus 4 digits, set by CBS with the Ministry of the Interior (BZK). A rename changes the code. |
| gemeentenaam | string | Official gemeente name. |
| provinciecode | string | Provincie code: `PV` plus 2 digits, from CBS StatLine table 86059NED. |
| provincienaam | string | Provincie name, from CBS StatLine table 86059NED. |
| landcode | string | Country code, always `NL`. |
| landnaam | string | Country name, always `Nederland`. |
| water | string | Always `NEE` (land). Water rows are left out. |
| jaar | int32 | Vintage year of the Wijk- en Buurtkaart. |

## Processing Notes

Built by `scripts/catalog/tools/build_demo.py` in [cod-site](https://github.com/OCHA-DAP/cod-site) from the land rows of `nld/2025/nld_admin2`: `ST_CoverageSimplify` at 100 m, then `ST_CoverageClean` with 0.01 m snapping and no gap filling. Provincie columns joined on `gemeentecode` from the CBS StatLine [OData table 86059NED](https://opendata.cbs.nl/ODataApi/odata/86059NED/TypedDataSet?$format=json&$select=RegioS,Code_28,Naam_29).
