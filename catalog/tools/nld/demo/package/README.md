# Gemeenten 2025 for package

The 342 gemeenten from the `edge` demo after edge-match, filling their provincies including water, in OGC:CRS84. Each carries adm0 `NL`, its provincie as adm1 from Kadaster and its CBS code and name as adm2. Running package writes country, provincie and gemeente polygons, one point per unit and the boundary lines. See [AGENTS.md](AGENTS.md).
