# Gemeenten and provincies 2025

An input and a join layer for schema-join, in OGC:CRS84, simplified to 100 m. `nld_admin2.parquet` has the 342 land gemeenten from the CBS Wijk- en Buurtkaart 2025, with `adm2_code` and `adm2_name`. `nld_admin1.parquet` has the 12 provincies from Kadaster Bestuurlijke Gebieden, with `adm1_code` and `adm1_name`. Running schema-join copies each gemeente's provincie code and name onto it. See [AGENTS.md](AGENTS.md).

## Processing Notes
