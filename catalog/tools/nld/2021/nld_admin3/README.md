## Schema

| Column | Type | Description |
|--------|------|-------------|
| geometry | binary | Polygon or MultiPolygon in OGC:CRS84, reprojected from EPSG:28992 (RD New). Gemeente boundaries come from Kadaster BRK and the land/water split from CBS Bestand Bodemgebruik. Not generalized. |
| wijkcode | string | Wijk (district) code: `WK` plus 6 digits (4 gemeente, 2 wijk). |
| wijknaam | string | Wijk name, as set by the gemeente. |
| gemeentecode | string | Gemeente (municipality) code: `GM` plus 4 digits, set by CBS with the Ministry of the Interior (BZK). A rename changes the code. |
| gemeentenaam | string | Official gemeente name. |
| water | string | `JA` water, `NEE` land, `B` Belgian territory around Baarle-Nassau (gemeente `GM0998` Buitenland). |
| jaar | int32 | Vintage year of the Wijk- en Buurtkaart. |
